**Turtle City** — a colossal ancient sea turtle swims through a burning sunset sky, carrying an entire glowing miniature city on its shell — tiny lit windows, little towers and a small lighthouse on its back — while tiny hot-air balloons orbit around it. One impossible moment: a whole city, riding a turtle through the clouds.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program (Node 22, standard library only) decodes the embedded image and writes it to `/output/entry.png` (`$MAKEFUN_OUTPUT_DIR` outside the grader). No network, no randomness: two runs write byte-identical output. The image is a JPEG, 1024×1024, 256,805 bytes (under the 1 MiB cap); the gate tells PNG from JPEG by its first bytes and the name stays `entry.png`.
