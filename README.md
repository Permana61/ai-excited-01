**Lighthouse Dragon** — on a stormy night, a small lighthouse's beam of light turns mid-air into a colossal golden dragon made of pure light, coiling over a dark sea while a tiny sailor in a yellow raincoat watches from the rocks far below. One impossible moment: the light itself came alive.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program (Node 22, standard library only) decodes the embedded image and writes it to `/output/entry.png` (`$MAKEFUN_OUTPUT_DIR` outside the grader). No network, no randomness: two runs write byte-identical output. The image is a JPEG, 1024×1024, 272,543 bytes (under the 1 MiB cap); the gate tells PNG from JPEG by its first bytes and the name stays `entry.png`.
