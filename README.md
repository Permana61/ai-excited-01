**Moon Phoenix** — the full moon cracks open like a giant eggshell and a colossal phoenix with blazing orange-gold wings bursts out of it in a shower of embers and moon shards, over a tiny sleeping coastal city with a miniature lighthouse far below. One impossible moment: the moon was never the moon — it was an egg.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program (Node 22, standard library only) decodes the embedded image and writes it to `/output/entry.png` (`$MAKEFUN_OUTPUT_DIR` outside the grader). No network, no randomness: two runs write byte-identical output. The image is a JPEG, 1024×1024, 355,755 bytes (under the 1 MiB cap); the gate tells PNG from JPEG by its first bytes and the name stays `entry.png`.
